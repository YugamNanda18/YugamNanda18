# 🏛️ Flagship Production Project

### **FLOWW (LedgerX) — Enterprise Institutional Fee & Academic Governance Platform**
> 🔗 **Live Production App:** [floww-gamma-gilt.vercel.app](https://floww-gamma-gilt.vercel.app)  
> 🔗 **Live Backend API:** [floww-api.onrender.com](https://floww-api.onrender.com)  
> 💻 **GitHub Repository:** [github.com/YugamNanda18/Floww](https://github.com/YugamNanda18/Floww)

```
                       ┌──────────────────────────────────────────────┐
                       │          React SPA (Vite + Vercel)           │
                       └──────────────────────┬───────────────────────┘
                                              │ HTTPS / JWT Auth
                                              ▼
                       ┌──────────────────────────────────────────────┐
                       │          Node.js API (Render Cloud)          │
                       │     (Zero-Trust 4-Tier RBAC + Idempotency)    │
                       └───┬──────────────────┬───────────────────┬───┘
                           │                  │                   │
                           ▼                  ▼                   ▼
                 ┌──────────────────┐ ┌───────────────┐ ┌──────────────────┐
                 │  MongoDB Atlas   │ │  Redis Cloud  │ │ Razorpay Webhook │
                 │ (Double-Entry    │ │ (BullMQ Queue │ │  (SHA-256 HMAC   │
                 │  Ledger Record)  │ │ + Cache Sync) │ │   Verification)  │
                 └──────────────────┘ └───────────────┘ └──────────────────┘
```

* **Mathematical Ledger Invariant**: Engineered double-entry ledger mechanics guaranteeing that every student fee assessment and settlement balances with zero mathematical drift (`Debit === Credit`).
* **Idempotent Payment Webhooks**: Implemented atomic payment capture handling Razorpay webhook events with HMAC-SHA256 signature verification and unique index constraints, preventing duplicate receipt issuance.
* **Real-Time Multi-Service Synchronization**: Automated student cohort placement (Year, Semester, Branch, Batch) that simultaneously synchronizes state across MongoDB Atlas, Redis Cloud cache keys, and live departmental rosters.
* **Distributed Queue Engine**: Designed BullMQ background workers backed by Redis Cloud for midnight automated late-fee compounding and multi-channel compliance reminders.
* **Zero-Trust RBAC**: Four isolated governance tiers separating Institute Deans, Department HODs, Finance Accounts Administrators, and Students.
* **Tech Stack:** `React (Vite)`, `Node.js`, `Express`, `MongoDB Atlas`, `Redis Cloud`, `BullMQ`, `Razorpay`, `Tailwind CSS`.
